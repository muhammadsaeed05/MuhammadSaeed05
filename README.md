### 🚀 Featured Projects

**[TruEval](https://github.com/muhammadsaeed05/TruEval)** — LLM Evaluation Harness
An async-first evaluation framework for running structured test suites across OpenAI, Anthropic, and local models. Implements pluggable rule-based and LLM-as-Judge evaluators, and pins baseline runs in SQLite to automatically surface quality regressions after prompt or model changes — with CLI and HTML reporting for technical and non-technical stakeholders.
`Python` `LiteLLM` `SQLite` `LLM-as-Judge`

**[Agent Atlas](#)** — Multi-Agent Travel Planning System
A multi-agent system built on LangGraph's StateGraph with fan-out/fan-in orchestration across parallel specialist agents, integrating MCP tool servers (stdio + streamable_http, including a custom FastMCP weather server) and a multi-provider LLM gateway with automatic fallback routing and LangSmith tracing.
`LangGraph` `MCP` `FastAPI` `React/TypeScript` `LangSmith`
*(repo link: [ADD_PROJECT_URL])*

**[SlimPrompt](#)** — Prompt Compression & RAG Optimization Middleware
Middleware sitting between RAG retrieval and the LLM context window that cuts token usage up to 80% using LLMLingua-2, with semantic deduplication of retrieved chunks and a binary-search-based "Compression Judge" that auto-calibrates compression ratios without manual tuning.
`Python` `LLMLingua-2` `Modal (GPU offload)`
*(repo link: [ADD_PROJECT_URL])*

**[ReadEase AI](#)** — Dyslexia-Friendly Text Transformer
An end-to-end NLP/RAG pipeline that converts unstructured text into dyslexia-friendly formats, using a domain-specific knowledge base to enforce accessibility-focused structural and readability transformations, with LangGraph pipeline execution traced via LangSmith.
`RAG` `LangGraph` `LangSmith` `NLP`
*(repo link: [ADD_PROJECT_URL])*
